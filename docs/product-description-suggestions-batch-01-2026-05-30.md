## Purpose

This batch tested a safe method for improving real product descriptions before applying changes to the wider live catalog.

Each suggestion uses one of these evidence levels:

- High: facts are visible in Cesar Store product data and/or supported by a matching public product reference.
- Medium: facts are visible in Cesar Store product data, but brand-specific claims were avoided.
- Needs owner review: the product needs confirmation from the package label, supplier, or owner before using stronger claims.

## Guardrails used

- Do not invent compatibility, performance, material, durability, or safety claims.
- Do not claim that an additive fixes mechanical damage.
- For fluids and additives, include cautious usage language.
- For lighting, cables, compressors, and tow tools, include compatibility/safe-use wording.
- Keep descriptions suitable for the product page, Merchant feed, and AI-readable summaries.
