# 📦 Cesar Store — System Bible (Production-Ready)

---

# 🧠 1. نظرة عامة (System Overview)

**Cesar Store** هو نظام E-commerce كامل يعتمد على:

* **Frontend:** Next.js (App Router)
* **Backend:** Next.js API Routes
* **Database + Auth:** Supabase
* **State Management:** React Context
* **Real-time:** Supabase subscriptions
* **External Integration:** WhatsApp API
* **Documents:** PDF Invoice (react-pdf)

---

# 🧱 2. المعمارية العامة (High-Level Architecture)

```text
Client (Next.js)
   ↓
API Layer (/api/*)
   ↓
Supabase (DB + Auth + Realtime)
   ↓
External Services (WhatsApp / PDF)
```

# 🔐 4. Security Architecture (RLS + Roles)

## 🛡️ Roles

| Role          | صلاحيات                |
| ------------- | ---------------------- |
| Customer      | يشوف ويعدل بياناته فقط |
| Admin         | Full access            |
| Catalog Admin | Read-only على Orders   |

---

## 🔒 RLS Policies

* user.id = owner
* منع access لأي بيانات غير مرتبطة بالمستخدم
* admin bypass
