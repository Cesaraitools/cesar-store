# 🧠 CORE ARCHITECTURE (DO NOT CHANGE)

## 1. 🔒 Source of Truth

* ✅ Database = **ONLY source of truth**
* ❌ Frontend NEVER trusted for:

  * cart
  * order items

---

## 2. 📦 Snapshot Architecture

* Orders store:

  * product name
  * price
  * image

❌ No dependency on products table after order creation

---

## 3. 🛒 Hybrid Cart System

### Guest:

```js
localStorage → cesar_store_cart_v2
```

### Logged-in:

* DB cart becomes source of truth
* Local cart = temporary buffer only

---

## 4. 🔁 Merge Strategy (CRITICAL)

### Endpoint:

```
POST /api/cart/merge
```

### Behavior:

1. Read localStorage + DB cart
2. Merge:

   * existing → increase quantity
   * new → insert
3. Save ONLY in DB
4. Clear localStorage

# 📡 API CONTRACTS (STRICT — DO NOT CHANGE)

---

## 🛒 GET /api/cart

### Response:

```json
{
  "cart": {
    "id": "...",
    "items": [
      {
        "product_id": "...",
        "quantity": 2,
        "price": 100
      }
    ]
  }
}
```

---

## 🔁 POST /api/cart/merge

### Behavior:

* No request body required
* Reads from localStorage (frontend)
* Merges into DB

### Response:

```json
{
  "success": true
}
```

---

## 📦 POST /api/orders

### ⚠️ IMPORTANT

* Does NOT accept items from frontend

### Request:

```json
{}
```

---

### Server Logic:

1. Resolve user
2. Fetch cart from DB
3. Validate products
4. Build snapshot
5. Create order
6. Insert tracking event
7. Clear cart AFTER success

---

### Response:

```json
{
  "order_id": "...",
  "order_number": "...",
  "status": "requested"
}
```
