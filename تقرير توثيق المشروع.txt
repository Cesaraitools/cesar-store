🔁 6. SYSTEM FLOW (كامل)
🟢 Add Product
Admin UI
→ Normalize Data
→ Check Duplicate
   → Yes → Skip
   → No
→ Upload Images (Smart)
   → Exists → reuse
   → New → upload
→ Save in DB
🟢 Bulk Import
Excel → Parse
→ Loop rows
→ Check duplicate
→ Upload only if valid
→ Save product
🟢 Upload System
File → Convert Base64
→ Compare with existing images
→ If match → reuse
→ Else → upload
🟢 Update Product
Get old images
→ Normalize new images
→ UPDATE DB FIRST
→ Fetch all images
→ Compare (old vs new)
→ Delete unused safely
🟢 Delete Product
Get product images
→ Get all other products images
→ Check usage
→ Delete unused
→ Delete product
💣 7. IMAGE LIFECYCLE SYSTEM
UPLOAD:
✔ reuse if exists
✔ upload if new

UPDATE:
✔ delete old if unused

DELETE:
✔ delete only if safe

RESULT:
✔ No duplication
✔ No storage leak
✔ No data loss
